01 SOFTWARE DE INGENIERÍA

LVNetworkSim

Software para el análisis de redes de distribución eléctrica con enfoque en baja tensión.

El proyecto

LVNetworkSim surgió a partir de la recomendación de mi catedrático de Sistemas de Distribución, con el objetivo de desarrollar una herramienta capaz de representar diagramas unifilares y facilitar el análisis de redes eléctricas.

El software permite introducir parámetros básicos que pueden obtenerse en campo, como distancias entre postes, cantidad de acometidas y características de la red, para posteriormente realizar cálculos de caída de tensión y pérdidas de potencia.

Enfoque

El desarrollo se enfocó principalmente en redes radiales de baja tensión. Los cálculos fueron comprobados utilizando datos de campo provenientes de un estudio real de distribución, buscando que los resultados fueran aplicables al contexto de las redes utilizadas en Honduras.

Funcionamiento

El programa realiza cálculos de potencia y caída de tensión mediante ecuaciones eléctricas y procesos iterativos que reorganizan la información de la red para aplicar correctamente los cálculos a cada elemento.

El usuario puede modificar variables como el periodo de estudio, voltaje de operación y tipo de conductor. Entre los resultados principales se encuentran las pérdidas de potencia y el porcentaje de caída de tensión.

Desarrollo

Todo el software, desde el código de procesamiento hasta la interfaz gráfica y las guías de usuario, fue desarrollado por mí.

02 AUTOMATIZACIÓN Y ELECTRÓNICA

Automatización de mezcladoras

Prototipo académico funcional para automatizar el llenado y proceso de mezcla.

El proyecto

El proyecto consistió en desarrollar un prototipo inspirado en sistemas de mezclado de productos químicos líquidos en entornos cerrados, buscando reducir la intervención humana durante el proceso.

El sistema permite establecer parámetros desde un menú de comandos y ejecutar automáticamente un proceso de llenado dividido en tres etapas.

Control del proceso

Un sensor ultrasónico se utilizó para determinar la altura del líquido y estimar el volumen de llenado. El sistema utilizó indicadores LED para señalar las distintas etapas y circuitos basados en BJT como interruptores para controlar válvulas, motores y una bomba.

Desarrollo

El sistema fue desarrollado utilizando una Raspberry Pi como plataforma de control, funcionando como alternativa a un Arduino y permitiendo además realizar activaciones remotas mediante una conexión SSH desde dispositivos móviles.

Mi participación comprendió el diseño del sistema, programación, construcción, mejoras y optimización del prototipo de acuerdo con el presupuesto y la disponibilidad de componentes.

Fabricación

Como parte del desarrollo se diseñó e imprimió en 3D una hélice adaptada al motor disponible para realizar el proceso de mezcla.

03 DISEÑO ELÉCTRICO

Diseño de instalación eléctrica

Diseño eléctrico de iluminación y fuerza para una vivienda de una planta.

El proyecto

Proyecto académico desarrollado en colaboración con un compañero para el diseño de la instalación eléctrica de una vivienda de una planta.

La propuesta corresponde a una vivienda ubicada en un terreno aproximado de 14 × 24 m, con áreas interiores y exteriores que incluyen cuatro dormitorios, cuatro baños, cocina, sala, comedor, estudio, piscina, área social, lavandería y estacionamiento para dos vehículos.

Alcance

El diseño contempló circuitos, cargas, conductores, protecciones, tableros, puesta a tierra y cálculos de caída de tensión.

Criterios de diseño

La propuesta fue desarrollada siguiendo criterios establecidos por NFPA 70 (NEC), considerando aspectos como la ubicación de tomacorrientes, utilización de dispositivos GFCI en áreas que lo requieren, selección de equipos de A/C y diferentes soluciones de iluminación.

Entregables

El proyecto incluyó planos eléctricos, cuadro de cargas y memoria de cálculo, integrando la documentación necesaria para representar y justificar el diseño propuesto.
