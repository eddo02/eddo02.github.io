01 ENGINEERING SOFTWARE

LVNetworkSim

Electrical distribution network analysis software focused on low-voltage systems.

The project

LVNetworkSim was developed following a recommendation from my Distribution Systems professor, with the goal of creating a tool capable of representing single-line diagrams and facilitating electrical network analysis.

The software allows users to enter basic field parameters such as distances between poles, number of service connections, and network characteristics, and then perform voltage drop and power loss calculations.

Focus

Development focused primarily on radial low-voltage networks. The calculations were validated using field data from a real distribution study, helping adapt the results to the context of electrical networks used in Honduras.

How it works

The program performs power and voltage-drop calculations using electrical equations and iterative processes that reorganize network data so that the equations can be correctly applied to each element.

Users can modify variables such as the study period, operating voltage, and conductor type. The main results include power losses and percentage voltage drop.

Development

I developed the entire software, including the processing code, graphical user interface, and user guides.

02 AUTOMATION AND ELECTRONICS

Mixer Automation

Functional academic prototype for automating the filling and mixing process.

The project

The project consisted of developing a prototype inspired by closed liquid chemical mixing systems, with the goal of reducing human intervention during the process.

The system allows parameters to be configured through a command interface and automatically performs a three-stage filling process.

Process control

An ultrasonic sensor was used to determine liquid height and estimate the filling volume. LEDs indicated the different stages, while BJT-based switching circuits controlled valves, motors, and a pump.

Development

The system was developed using a Raspberry Pi as the control platform, serving as an alternative to an Arduino while also allowing remote activation through an SSH connection from mobile devices.

My participation covered the system design, programming, construction, improvements, and optimization of the prototype according to the available budget and components.

Manufacturing

As part of the development, I designed and 3D-printed a propeller adapted to the available motor to perform the mixing process.

03 ELECTRICAL DESIGN

Electrical Installation Design

Lighting and power design for a single-story house.

The project

Academic project developed in collaboration with a classmate to design the electrical installation of a single-story residential building.

The proposal corresponds to a house on an approximately 14 × 24 m plot, including four bedrooms, four bathrooms, kitchen, living and dining areas, study, pool, social area, laundry room, and parking for two vehicles.

Scope

The design included circuits, loads, conductors, protection devices, panels, grounding, and voltage-drop calculations.

Design criteria

The proposal followed criteria established by NFPA 70 (NEC), considering aspects such as receptacle placement, GFCI protection in applicable areas, A/C equipment selection, and different lighting solutions.

Deliverables

The project included electrical drawings, a load schedule, and calculation documentation to represent and support the proposed design.
